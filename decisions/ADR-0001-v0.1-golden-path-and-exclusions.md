# ADR-0001: v0.1 Golden Path and Exclusions

## Status

DECIDED

## Context

enastro の構想は Digital Garden / Knowledge Graph / AI access など多岐にわたるが、
すべてを MVP に含めると基礎的な content semantics / privacy semantics が確立する前に
UI やクエリ層へ投資してしまうリスクがある。

## Decision

v0.1 の一本道（golden path）は次のみとする。

```
minimal Markdown vault
  → frontmatter parse
  → publish selection (publish: true)
  → Wikilink resolution (+ backlink)
  → minimal graph IR
  → deterministic static artifact (HTML + search index)
  → automated verification
```

実行形態はローカル CLI のみ。次を v0.1 から明示的に除外する（[01-scope-and-requirements.md](../spec/01-scope-and-requirements.md) §3 参照）。

- Graph UI / WebGL レンダラー
- ローカル AI・Web AI 向け MCP / CLI query interface
- private → CI → public repo の自動公開パイプライン
- 非 Obsidian 入力形式
- mobile / accessibility 対応
- 10,000 nodes / 50,000 edges 規模の性能最適化
- 複数 vault 対応

タグ検索・フィルタリング UI は除外しない（v0.1 スコープに含む）。

## Consequences

- v0.1 は enastro の差別化要素である Graph UI を提示できないが、privacy-safe な
  compile → publish の中核価値を最速で検証できる。
- Graph UI・AI access 等は、基礎 semantics が固まった後続ループで追加する。
