# 禁書：マークダウン星辰儀

これは書ではない。読むためではなく、**書かれるために**存在する七つの巻物である。
[[markdown|Markdown]] という薄暗い土台の上に、各巻物は割り当てられた星の性質に従って
現れる。順序に疑問を持ってはならない。~~疑問を持ったところで何も変わらない~~。

## 土星の巻物 — 秩序と束縛

土星は最も遅く、最も古い。ゆえに最初に置かれる。手順は逆行せず、番号は乱れない。

1. `saturnus` の環を数える
2. 環はさらに細かい環を内包する
   1. 第一の環
   2. 第二の環
3. 最後の環に触れたとき、儀式は完了する

## 月の巻物 — 満ち欠け

月は分岐する。枝分かれした先でまた枝分かれする。

- 新月（無からの分岐）
- 上弦（枝分かれの兆し）
  - 三日月（さらに分かれた影）
  - 半月（もう一つの影）
- 満月（すべての枝が出揃う）

## 金星の巻物 — 装飾と魅了

金星は**濃く**輝き、*淡く*瞬き、時に ~~見えなくなる~~。硬い護符 `venus` だけは
どの光の下でも変質しない。

## 火星の巻物 — 衝突の記録

火星は変化を強いる。変化の前後は、こうして刻まれる。

```diff
- const fate = "sealed";
+ const fate = "rewritten";
```

## 水星の巻物 — 書記官の呪文

水星は書記官の守護星である。呪文はこの形のまま封じられる。

```javascript
function invoke(sigil) {
  return `${sigil} awakens`;
}
```

## 太陽の巻物 — 位階

太陽は序列を照らし出す。

### 熾天使の位（h3）
#### 智天使の位（h4）

見出しレベルが下がるほど、位は下がる。

## 天王星の巻物 — 数式

天王星は隠された法則を司る。質量とエネルギーの等価は、こう記される。
$E = mc^2$、あるいは並べて示せば

$$
\int_0^\infty e^{-x^2} \, dx = \frac{\sqrt{\pi}}{2}
$$

と顕現する。

## 封印された奥義

以下は、まだこの星辰儀に降ろせない奥義である。呼び出す言葉は書けても、姿を結ばない。

- mermaid（星座として結ばれるはずの図が、まだ個々の文字列のまま眠っている）
- `<details>`/`<summary>`（開閉の奥義。封印（サニタイズ allowlist）が解かれていない）
- `:::note info` / `:::note warn` / `:::note alert`（警告の色をまとう奥義。専用の祭壇が要る）
