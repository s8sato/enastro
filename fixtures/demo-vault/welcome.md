# ようこそ

これは [enastro](https://github.com/s8sato/enastro/) の Graph UI デモサイトです。すべてのノートは
[[zettelkasten]]・[[digital-garden]]・[[second-brain]]・[[obsidian]]・[[knowledge-graph]] を
中心に、個人の知識管理（PKM）についての小さなメモとして書かれています。

右上の「Graph view」から、これらのノートがどうつながっているかを星空のグラフとして
眺めることができます。

このノートは非公開ノート [[private-draft]] にもリンクしていますが、そのリンクは
公開 artifact から自動的に取り除かれます（privacy invariant）。
